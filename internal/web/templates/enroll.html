Enroll a PC

Takes about a minute per PC. Works on Windows 10 and 11 Pro, Business, Education and Enterprise.

Quickest way: the enrollment link

  1. On the PC, open this page and click Enroll this PC
  2. Windows opens Set up a work or school account. Type any email for the person using the PC.
  3. When asked for a password, enter the enrollment password you set in KEYSTONE_ENROLL_SECRET.
  4. Click Done. The PC appears on the Devices page within a minute.

Manual way

  1. Open Settings → Accounts → Access work or school.
  2. Choose Enroll only in device management.
  3. Enter an email whose domain matches your server, for example you@yourdomain. Windows looks up enterpriseenrollment.yourdomain.
  4. If asked for a server, use {{.PublicURL}}.
  5. Enter the enrollment password.

To unenroll, remove the work account from the same Settings page.
